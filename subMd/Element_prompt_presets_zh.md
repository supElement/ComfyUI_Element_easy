# Element Prompt Presets 使用说明

一个本地提示词库节点：按 **分类 → 词条** 选择提示词，在文本框里查看/修改后输出给下游；也可以多选一批词条，输出单段合并文本和文本列表。整行/整段可按 seed 抽取。

预设数据（含 tags 标记）全部保存在 `ComfyUI/user/element_easy/promptPresets/prompts.json`；未标记的词条默认为自然语言。旧版遗留的 `prompt_tags.json` 会在首次读取时自动并入并删除。

## 一、参数

| 参数 | 作用 |
|---|---|
| presets | 分类（例如 幻想 / 写真 / 叙事） |
| entry | 当前分类下的词条；标记为 tags 的词条名称后显示一个实心圆点 `⬤`（仅显示，输出文本不含该符号） |
| single_line | 开启后每段文本只输出**一行**；关闭则输出整段原文 |
| seed | 挑选行号用的种子 |
| prompt_text | 提示词文本框，显示所选词条的内容，可直接编辑 |
| link | 多选条目合并成单段文本时的分隔符，默认 `, ` |

> `selection` 是多选状态，由「选择条目」弹窗自动维护并随工作流保存，不在节点上显示。

> 修改文本框内容后，要按「保存词条」按钮（软盘图标）才会写回库，否则只影响当前这次运行。

> tags 指关键词式提示词，Natural language 指自然语言描述；导入的预设和改版前的旧预设默认都是 Natural language。

## 二、按钮（从左到右）

| 图标 | 名称 | 作用 |
|---|---|---|
| 打开的文件夹 | 加载文件 | 导入 `.json` / `.xlsx` / `.csv`；分类重名时自动改为 `名称 (2)` |
| + | 新建词条 | 在指定分类下新建词条，并把当前文本框内容存进去；可勾选 `tags | 标签`，左下角 `Modify Tags | 修改标签` 切换当前词条的 tags 标记 |
| 勾选清单 | 选择条目 | 打开多选弹窗，选择多个词条输出，或直接删除词条 / 分类 |
| 软盘 | 保存词条 | 把当前文本框内容保存到当前分类 / 词条 |
| 垃圾桶 | 删除词条 | 删除当前词条（若它是分类里最后一个，分类一并删除） |
| 文件夹叉 | 删除分类 | 删除整个分类及其全部词条 |
| 包裹 | 导出 | 把**全部预设**导出为一个 JSON，可存到任意磁盘 / 文件夹 |
| 圆圈叉（最右） | 清空 | 清空所有预设，会先弹确认；不影响已导出的 `.json` 文件 |

## 三、多选弹窗（选择条目）

点工具栏的勾选清单按钮打开：

- 按「分类 → 词条」显示全部预设，分类右侧箭头可折叠；
- 点击词条切换选中状态，选中为蓝色；分类下任意词条被选，分类标题也变蓝；
- 点击分类标题 = 选中 / 取消该类目下**当前可见**的全部词条；
- `tags | 标签` 与 `Natural language | 自然语言` 两个过滤按钮默认都开启：只开 tags 时隐藏自然语言词条，只开自然语言时隐藏 tags 词条（至少保留一个开启）；开关状态按节点分别记住，下次打开该节点的弹窗只影响它自己（保存在浏览器本地）；
- `select All | 全选` 选中当前可见的全部词条；`clear select | 清空选择` 清空全部选择；
- `delete | 删除` 开关：开启后词条和分类右上角出现红色 ×；点词条的 × 删除该词条，点分类的 × 删除整个分类（会先确认）；
- `link | 分隔符` 输入框与节点上的 link 参数同步；
- 弹窗可拖动右下角改变大小，尺寸会记住；
- 右下角 `Apply` 按钮确认选择并关闭；选择其实在点击时就已写入节点，关闭弹窗不会丢失；
- 选择状态随工作流保存，重新打开弹窗会保持上次的选择；库中被删除的词条会自动跳过。

> 关闭弹窗后，节点仍然用 presets / entry 显示「当前词条」；多选与当前词条互不影响。

## 四、输出端口

| 端口 | 内容 |
|---|---|
| prompt_text | 单段文本：没有多选时输出当前词条（原行为）；有多选时把每个选中词条按 link 拼接 |
| prompt_list | 列表：没有多选时是 `[当前词条文本]`；有多选时是每个选中词条的文本列表 |

- 顺序按弹窗中的分类 / 词条显示顺序；
- `single_line` 开启时，每个选中词条先各取一行，再分别用于拼接 / 列表；每个词条的行由 `seed + 分类 + 词条` 哈希派生，**互不相同**（见第五节）；
- `prompt_list` 接普通文本节点时 ComfyUI 会按列表逐项执行，接支持列表的节点则拿到整个列表；
- 若选中的词条在库中已被删除，会自动跳过；全部失效时退回当前词条。

## 五、single_line 与 seed

开启 `single_line` 后，当前词条（以及每个选中词条）从各自的文本里挑一行输出。挑选规则：

1. 按换行取行，**跳过空行**（段落之间的空行不会输出空结果）；
2. 行号 = `seed % 行数`：seed 再大也只会映射到有效行，不会总落在最后一行。

多选时每个词条使用独立的派生种子，而不是共用同一个 seed：

- 派生种子 = `hash(seed, 分类, 词条)`，所以同一 seed 下各词条的行号彼此无关，换 seed 时也不会同步跳转；
- 若 N 个词条各有 n₁…n_N 行，可组合出的结果约 `n₁ × n₂ × … × n_N` 种（共用同一 seed 时最多只有它们行数的最小公倍数种）。

| 生成方式 | 行为 |
|---|---|
| 固定 fixed | seed 不变，永远同一组行 |
| 增量 increment | 每次运行后 seed +1，各词条独立换行，组合近似随机遍历 |
| 减量 decrement | 每次运行后 seed −1，各词条独立换行 |
| 随机 random | 每次运行前换随机 seed，组合均匀随机 |

## 六、导入文件

### 4.1 JSON

```json
{
  "幻想": {
    "巨龙山": "第一段提示词……",
    "麦田": "另一段提示词……"
  },
  "写真": {
    "白衬衫": "……"
  }
}
```

也支持：

- 单分类文件：`{"词条名": "文本", ...}`，导入后归类到文件名；
- 外层包装：`{"presets": { ...上面结构... }}` 或 `{"categories": { ... }}`；
- 带 tags 的导出格式：词条值为对象 `{"text": "文本", "tags": true}`；同一分类里可以与纯文本混用，未标 tags 的仍按自然语言处理。

```json
{
  "幻想": {
    "巨龙山": {"text": "关键词式提示词……", "tags": true},
    "麦田": "自然语言描述……"
  }
}
```

### 4.2 表格（.xlsx / .csv）

按三列读取：**分类 | 词条 | 文本**。示例：

| 分类 | 词条 | 文本 |
|---|---|---|
| 人文场景 | 山顶 | 第一段提示词…… |
|  | 高原 | 另一段提示词…… |
|  | 卧室 | …… |
| 梦幻场景 | 奇幻森林 | …… |

- 不做表头判断：表头行也和普通数据一样导入（不需要时删掉即可）；
- 表格左侧的空列、整列都是空白的列会被忽略；只有一格内容的行（如标题）会跳过；
- 分类列合并单元格、或只在第一行写名称时，下面空着的行沿用上面的分类；
- 全空行自动跳过；同一分类里词条重名时存为 `名称 (2)`；
- 只有「词条 | 文本」两列时，全部归到文件名这个分类下；
- 文本列可以有多行内容；工作簿里的所有工作表都会被读取；
- WPS / Excel 直接保存为 `.xlsx`；Google 表格用「文件 → 下载 → Microsoft Excel / CSV」；
- 旧版 `.xls` 请先在表格软件里另存为 `.xlsx`。
