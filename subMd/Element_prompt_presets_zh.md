# Element Prompt Presets 使用说明

一个本地提示词库节点：按 **分类 → 词条** 选择提示词，在文本框里查看/修改后输出给下游，并可把整行或整段按 seed 抽取。

预设数据保存在 `ComfyUI/user/element_easy/promptPresets/prompts.json`。

## 一、参数

| 参数 | 作用 |
|---|---|
| presets | 分类（例如 幻想 / 写真 / 叙事） |
| entry | 当前分类下的词条 |
| single_line | 开启后只输出文本框里的**一行**；关闭则输出整段原文 |
| seed | 挑选行号用的种子|
| prompt_text | 提示词文本框，显示所选词条的内容，可直接编辑 |

> 修改文本框内容后，要按「保存词条」按钮（软盘图标）才会写回库，否则只影响当前这次运行。

## 二、按钮（从左到右）

| 图标 | 名称 | 作用 |
|---|---|---|
| 打开的文件夹 | 加载文件 | 选择任意位置的 `.json` 导入；分类重名时自动改为 `名称 (2)` |
| + | 新建词条 | 在指定分类下新建词条，并把当前文本框内容存进去 |
| 软盘 | 保存词条 | 把当前文本框内容保存到当前分类 / 词条 |
| 垃圾桶 | 删除词条 | 删除当前词条（若它是分类里最后一个，分类一并删除） |
| 文件夹叉 | 删除分类 | 删除整个分类及其全部词条 |
| 包裹 | 导出 | 把**全部预设**导出为一个 JSON，可存到任意磁盘 / 文件夹 |
| 圆圈叉（最右） | 清空 | 清空所有预设，会先弹确认；不影响已导出的 `.json` 文件 |

## 三、single_line 与 seed

开启 `single_line` 后，从文本框里挑一行输出。挑选规则：

1. 按换行取行，**跳过空行**（段落之间的空行不会输出空结果）；
2. 行号 = `seed % 行数`：seed 再大也只会映射到有效行，不会总落在最后一行。

| 生成方式 | 行为 |
|---|---|
| 固定 fixed | seed 不变，永远同一行 |
| 增量 increment | 每次运行后 seed +1，逐行向下轮，到末尾回到第一行 |
| 减量 decrement | 每次运行后 seed −1，逐行向上轮 |
| 随机 random | 每次运行前换随机 seed，行号均匀随机 |

## 四、导入 JSON 的结构

```json
{
  "幻想": {
    "巨龙山": "第一段提示词……",
    "麦田": "另一段提示词……"
  },
  "写真": {
    "白衬衫": "……"
  }
}
```

也支持：

- 单分类文件：`{"词条名": "文本", ...}`，导入后归类到文件名；
- 外层包装：`{"presets": { ...上面结构... }}` 或 `{"categories": { ... }}`。
