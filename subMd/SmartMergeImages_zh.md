# Smart Merge Images 使用说明

把 AI 改过的局部图片，按正确位置、正确大小放回原图，并把接缝和色差处理干净。
输入可以是单张，也可以是多块（每块尺寸可以不一样），一次执行输出一张或多张合并图（取决于 merge_mode）。

**类别**：`Element_easy/image`，输出：`Merged_Image`（IMAGE）

---

## 一、最少怎么接

    原图 ─────────────► original_image
    AI 编辑后的块 ─────► edited_crop_B
    编辑前裁块(可选) ──► original_crop_A     ← 强烈建议接，最稳
    ElementTileSplit 的 grid(可选) ► split_grid  ← 用 TileSplit 拆分时就接上

- **接 `original_crop_A`**：节点知道每块原本在画面的哪里，对位最准，还能自动修局部变形（TPS 桥接）。
- **接 `split_grid`**：贴图边缘的渐变/圆角与 ComfyUI-Element_TileEdit 扩展中的 TileSplit 节点的grid完全一致，多块拼接不会有硬边。若 grid 携带 work_w/work_h，原图会先 resize 到该工作画布尺寸再合成。
- 都不接也能用：节点会在背景上自动找位置，但复杂画面偶尔会贴歪，此时对位失败的分块会被**跳过**（保留原图，不会硬贴到画面中间）。

**推荐的初始参数**

| 参数 | 建议 |
|---|---|
| 形变校正 `warp_method` | 开 |
| 光流模式 `optical_flow` | 开（慢一点） / 关（快） |
| TPS `use_tps` | 开 |
| 平滑 `warp_smooth` | 默认 1.0，若局部产生波浪状扭曲，适当提高 |
| 色彩匹配 `color_match` | `Patch_based_color` |
| 色相保护 `color_protection` | 关（默认）。开启后编辑区色彩不再被拉向背景，若没有编辑色相，建议关。 |
| 羽化 `feather_kernel` | 20~40（拼接缝明显时加到 40~60） |
| `use_gpu` | 开（默认） |

---

## 二、每个参数对结果的影响

### 1. 形变校正 `warp_method`（默认关）
决定"贴图时要不要修 AI 重绘造成的局部变形"。
- **关**：只做整体定位（单应性），纯几何。如果 AI 画歪了线条，这里不会修。
- **开**：在定位基础上，依靠 TPS 和光流继续修细节错位（表情、衣褶、边缘轻微变形）。

### 2. 光流模式 `optical_flow`（默认关，仅 `warp_method` 开时生效）
- **关 = Farneback**：CPU 算法。
- **开 = DIS**：质量更好，边缘更干净，推荐。

> **注意**：光流（全局和局部）的物理本质只适合做**微调**（局部约 10~15px，全局 12px 限幅）。如果发现大错位，光流是救不回来的，必须靠 TPS。

### 3. 非刚性校正 `use_tps`（默认开）
- **开**：允许轻度弯曲/拉伸去贴合背景。AI 重绘常见的"内容对了但形状差一点"靠它修。
- **关**：只做整体平移缩放旋转（若 `warp_method` 开，仍有光流精修）。

### 4. 精修平滑 `warp_smooth`（默认 1.0，0~4）
只在最后一步"整图精修"里起作用，控制修正位移的平滑程度。
- **0 ~ 1.0（温和）**：允许更细碎的位移修正，可能更贴合，也更容易出现轻微抖动。
- **1.0 ~ 2.0（强力）**：旧版最保守的平滑度，修正更平缓。
- **2.0 ~ 4.0（极强）**：强制光流场低频化，几乎不会产生任何局部扭动。

### 5. 色彩策略 `color_match`（默认 `Patch_based_color`）
对成品观感影响最大的参数。**五种模式是从"会改色"到"不改色"的渐变**：

| 模式 | 作用 | 适合 | 注意 |
|---|---|---|---|
| `Patch_based_color` | 分块校正色差，逐区域对齐背景色调 | 色差大、不均匀；多块拼接 | 最慢；但如果开了保护，编辑区会保留 |
| `LAB_Mean` | 整块按均值/方差对齐到背景 | 色差单一、想快速出图 | 内容大改的区域可能被整体冲淡 |
| `Laplacian Pyramid Blend` | 先做亮度匹配，再多频段融合解决接缝 | 颜色接近，只需亮度匹配和接缝处理 | 只做亮度匹配（L 通道中位平移），不做色彩（a/b）校正 |
| `SeamlessClone (PS Auto Blend)` | 先做亮度匹配，再泊松融合 | 内容基本没变，只想去接缝 | 内容大改区域会褪色/发灰，慎用 |
| `Alpha Soft Blend` | 仅羽化混合 | 几乎没色差修复，最快 | 有色差时完全不处理 |

### 6. 色相保护 `color_protection`（默认关）
**只影响色彩匹配链**（全局 LAB 粗校正 + 分块精校正）。
- **关（默认）**：色彩匹配不区分编辑/未编辑像素，整块按背景色调统一，编辑区也被拉向背景色，校正最强。
- **开**：只用未编辑像素估计色差，并减弱编辑区内的色彩校正。AI 改色被保留，但编辑区与背景的色差也一并保留。

### 7. 羽化 `feather_kernel`（默认 20，0~256）
贴图边缘的柔和过渡宽度，也决定色彩校正的"分块大小"。
- **调大（30~60）**：接缝更柔。如果发现边缘有"生硬的断层/错位"，加大羽化是最直接、最安全的掩盖方法。
- **调小**：边缘更利落，但会暴露出像素级的错位切边。

### 8. 合并方式 `merge_mode`（默认 All to One）
- **All to One**：所有编辑块按顺序贴回**第一张**背景，输出 1 张。
- **One to One**：背景与编辑块按数量均分配对，输出数量与背景相同。

### 9. `use_gpu` 与 `force_recompute`
- **`use_gpu`**（默认开）：加速特征匹配（DISK/LoFTR）与色彩匹配。OpenCV 步骤（光流、TPS/warp、无缝克隆）仍在 CPU 运行。
- **`force_recompute`**（默认关）：修改色彩模式/羽化不会重新对齐（对齐缓存容量 4 组，LRU）；勾选此项可强制清缓存从头对齐。

## 三、常见问题速查（排错指南）

| 现象 | 处理方案 |
|---|---|
| **边缘有生硬的"硬切边/断层"** | 1. 调大 `feather_kernel` 到 40+ <br>2. 关闭 `color_protection`（开启时编辑区色彩不被校正，色差保留） <br>3. 确认 `warp_method` 已开启，让光流介入。 |
| **局部远端（如画面边缘的人脸）未对齐** | 原版 TPS 有距离衰减和限幅保护机制，防止画面扯烂。若远端错位严重：<br>1. 必须接上 `original_crop_A` 使用桥接路线。<br>2. 适当降低 `warp_smooth` 允许光流微调。 |
| **局部变形没修好** | 确保 `use_tps` 开 + `warp_method` 开；检查日志是否有 `TPS 拒绝` 的提示。 |
| **分块贴歪或缺失** | 接 `original_crop_A`；日志会提示哪块因无可靠放置被跳过。 |
| **颜色被冲淡/发灰** | 换 `Patch_based_color`；不要用 `SeamlessClone`。 |

## 四、输入输出说明

- 三个图像端口都支持**单张 / 批量 / 列表**，不需要额外的 "Image List To Image Batch" 节点。
- 每块编辑图可以尺寸不同，节点按各自原始分辨率处理。
- `original_crop_A` 数量/尺寸与 B 不必严格一致，按顺序配对。
- 输出：`All to One` 为 1 张；`One to One` 为与背景数量相同的 batch。
- 无法可靠定位的分块会被跳过并在日志中列出，对应区域保留原图内容。
