# Image Pad & Blur（图像扩展与模糊）

给图像添加边距（扩图/画布扩展），可选对背景做模糊，或对原图像边缘做羽化过渡。所有操作在节点画布上直接拖拽完成，实时预览。

## 输入 / 输出

| | 名称 | 说明 |
|---|---|---|
| 输入 | `image` | 源图像（必需） |
| 输入 | `mask` | 可选遮罩，见下方「遮罩用法」 |
| 输出 | `image` | 处理后的图像 |
| 输出 | `mask` | 输出遮罩（白色 = 填充/扩边区域，可直接用于 inpaint） |

## 快速上手

1. 连接任意图像来源（Load Image、采样器等均可）；
2. 点击左上角**蓝色播放按钮**：只运行本节点及其上游链，刷新画布源图。**首次使用必须点一次，才能呈现画布预览并进行调整**；
3. 在画布上拖拽图像调整位置，拖拽边缘/四角调整大小；
4. 正常运行工作流，输出结果。

## 界面说明

### 顶栏（从左到右）

| 控件 | 功能 |
|---|---|
| ▶ 播放（蓝色） | 隔离预览：仅运行本节点 + 上游链并刷新画布，不影响工作流其余部分 |
| 颜色块 | 指定纯色填充模式的背景色 |
| 宽 × 高 | 图像在画布中的显示尺寸（可直接输入数值） |
| ⛶ Fit | 图像适配画布：重置缩放与位移 |
| 🔒 锁定 | 锁定宽高比；拖拽时按住 Shift 可临时反转 |
| ↺ Reset | 全部参数恢复默认 |
| 边框圆点组 | 选择哪些边做羽化过渡（上/下/左/右独立开关） |
| 九宫格 | 对齐方式（九个方位），切换时位移归零 |

### 画布

- **拖拽图像内部**：移动位置（像素级）；
- **拖拽边缘/四角**：调整图像大小；
- 画布左下角实时显示四边边距 `L/T/R/B`。

### 底栏（从左到右）

| 控件 | 功能 |
|---|---|
| 四个图标 | 填充模式：`constant` 纯色 / `edge` 边缘延伸 / `reflect` 镜像 / `stretch` 拉伸 |
| Feather | 羽化宽度（配合顶栏的边框圆点组，逐边线性渐变） |
| Blur | 背景模糊强度（对填充背景整体模糊） |
| 遮罩按钮 | 开启后，遮罩区域露出模糊背景（见下） |

## 节点属性参数

`target_width` / `target_height` 

- **> 0（画布模式）**：输出画布固定为该尺寸（自动对齐 `div` 的倍数），图像按对齐方式摆放，拖拽改变的是位移；
- **= 0（边距模式）**：输出尺寸 = 图像尺寸 + 四边边距，拖拽改变的是各边边距。

`div` 合法分辨率辅助设置参数

## 遮罩用法

1. 连入 `mask` 后，拖拽/缩放操作会同步带着遮罩走；
2. 顶栏边框圆点组：被选择的边才做羽化/受Feather参数影响；
3. 底栏遮罩按钮（默认关闭）：
   - **关闭**：遮罩只影响输出的 `mask` 通道（与羽化区域取并集）；
   - **开启**：遮罩区域在输出图像中露出模糊/填充的背景（图像内容在该区域被移除）。

## 使用提示

- 缩放以**比例**记录、位移以**像素**记录：更换源图或修改采样器宽高后，构图关系保持不变，无需重新调整；
- 输入图像若带 Alpha 通道会被忽略（按不透明 RGB 处理）；
- 播放按钮在刷新页面后首次点击即可生效，不必先跑完整工作流。但要注意，若上游有推理采样节点，需等推理结束，才会刷新画布。
