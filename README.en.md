# ComfyUI_Element_easy


A collection of small nodes for convenient use. Due to laziness, the code has not been merged. Includes: Element Load and Edit Video, Minimax_H3-LatentUpscaler, Smart merge images, LoadImage_Preview, Element_SigmaGraph, Element ImageCurve, Element HueSat, Element HueBright, Element HueHue, Frame Calculator, ImageSize Div, black_white_color, chessboard, empty_image_rgb, image_pad_blur, mask_noise_element, mask_stroke, random_chars, text_line_break.


## Installation

### Manual Installation (Manual Installation)<br>

   Go to the ./ComfyUI/custom_nodes directory and run the following code:<br>

      git clone https://github.com/supElement/ComfyUI_Element_easy.git
      cd ComfyUI_Element_easy
      pip install -r requirements.txt
  Optional: ffmpeg
  The video export (with audio) function of the node requires ffmpeg to be installed on the system. Download from <a href="https://www.gyan.dev/ffmpeg/builds/">ffmpeg</a> on Windows, unzip, and add the bin directory to PATH
  All other functions work normally without ffmpeg installed, only exporting as silent video


### Install using Manager (Install using Manager)<br>

  - Search for ComfyUI_Element_easy in the ComfyUI manager, then install.
 


## Update

## v1.5.4

- Added Element Load and Edit Video video loading and simple single-track editing nodes, and related auxiliary nodes Element Video Clip and Element Video Info.
- Element Load and Edit Video is a "visual single-track video editor" node: after importing the video, it can automatically detect shot cuts (PySceneDetect), and manually trim, rearrange, and preview clips on the interactive timeline, and one-click deliver the clip results to downstream nodes for output of images and audio.
- Its core value lies in: embedding the "cutting - rough cut - taking clips" process that traditionally needs professional editing software directly into the ComfyUI workflow, so that video batch processing and fragment generation workflows can be completed without leaving the canvas.
- Most of the time, it can replace the load video node.
- PS: The original name of the node was Element scene detection, after multiple functional modifications, this name can no longer reflect the function of the node, so the node name has been changed to Element Load and Edit Video

## v1.5.3

- Added "P" button to Element_SigmaGraph node.
- The behavior of the "P" button: When the number of points is less than steps+1, the x of the first n-1 points is rearranged to 0, 1/steps, 2/steps, ..., (n-2)/steps, and y remains unchanged; the last point (x, y) is retained as is. When the number of points is not less than steps+1, take the first steps+1 points, x is evenly distributed as 0, 1/steps, ..., 1, and y remains unchanged. Undo support: the operation will be pushed into the undo stack, and can be undone with Ctrl+Z.
- PS: What is the use? Increase the sampling steps (increase the detail) without changing the step size of the previous steps.


## v1.5.0
  
Added Minimax_H3-LatentUpscaler latent space scaling node, which only scales the latent space of the video and does not do any processing on the audio, the output port is Minimax H3 latent.
Added Minimax_H3-LatentUpscaler_Adv  latent space scaling node with verification. Introduces conditional scaling mode, which can be selected to ignore (pass_through), only align without scaling (NO_refs), or scale (refs). The quality is best in the refs scaling mode.

## v1.4.3（Optimized in V1.4.8）
  
  Added Smart merge images node.
  - Merge images intelligently when there are enough common features between the two images.
  - Correct the pixel offset and color difference generated by the editing model (Flux2 Klein, Qwen Edit, etc.) after editing images. The usage method in this case: connect the original image and the edited image after editing to the input ports original_image and edited_crop_B, respectively.
  - When merging the cropped image back into the original image, if the conditions allow, the most reliable merging scheme: original_image + edited_crop_B + original_crop_A. Among them, original_crop_A is the unmodified or deformed image cut from original_image.
  - Add color matching mode Adaptive Local (strong), which can better repair the color difference generated after the image is edited. Two new parameters are added specifically for this mode: adapt_thresh (color difference threshold).
  - Add adapt_local_match parameter, providing more options for mask fusion in the color matching mode Adaptive Local (strong).
  - Optimize the fusion method of Smart merge images node, and has better correction for the pixel offset and color offset generated after the image is edited by the editing model (Flux2 Klein, Qwen Edit, etc.). 
  - Add support for block merging of Smart merge images node. That is, when multiple images are input to the edited_crop_B port, the output is a single merged image. Note: The images input to the edited_crop_B port must be Batch rather than list. If it is a list, it must be converted through the Image List To Batch node.

## v0.0.6

Empty Image RGB：Supports RGB and 16-bit color information input, the node will automatically identify the color information color_code. Outputs a pure color image, with an image size output port, the image size will be approximated according to divisible_by (integer division).

Text Line Break： Breaks the input text by the number of characters, supports Chinese, English, and mixed Chinese and English, supports punctuation avoidance at the beginning and end. Convenient to connect prompts and generated images together, which requires other nodes, such as the Add Label node in Kjnode. Random Chars (Append)：Appending invalid special characters (can customize characters and number) to the input text, mainly to make the generated image have more changes without destroying the prompt intention (whether it works or not), because the random changes in the image composition generated by qwen_image and Z_image models are small. Here "invalid" is relative.
                       Can simply set the insertion position (before, end, insert), where insert is to evenly distribute the number of characters inserted into the original text after each punctuation mark, from the end to the front.
