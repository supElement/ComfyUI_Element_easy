# ComfyUI_Element_easy


Some convenient nodes for use. Because of laziness, the code has not been merged. Including: black_white_color, chessboard, empty_image_rgb, image_pad_blur, mask_noise_element, mask_stroke, random_chars, text_line_break. Element_SigmaGraph, Element ImageCurve, Element HueSat, Element HueBright, Element HueHue, LoadImage_Preview, Frame Calculator, ImageSize Div, Smart merge images


## Installation

- **Manual Installation**<br>
Navigate to the ./ComfyUI/custom_nodes directory and run the following code:<br>

      git clone https://github.com/supElement/ComfyUI_Element_easy.git

- **Install using Manager**<br>
Search for ComfyUI_Element_easy in the ComfyUI manager and then install.

## v1.4.3（Optimized in V1.4.7）
  
  Added Smart merge images node.
  - Smartly merge images when there are sufficient common features between two images.
  - Correct the pixel offset and color difference generated by the editing model (Flux2 Klein, Qwen Edit, etc.) after editing images. The usage method in this case: connect the original image and the edited image to the original_image and edited_crop_B input ports, respectively.
  - When merging the cropped image back to the original image, if the conditions permit, the most reliable merging scheme: original_image + edited_crop_B + original_crop_A. Where original_crop_A is the image cropped from original_image without modification or deformation.
  - Optimized the fusion method of Smart merge images node, with better correction for pixel offsets generated by editing models (Flux2 Klein, Qwen Edit, etc.). 
  - Added color matching mode Adaptive Local (strong), which can better repair the color difference generated by the image after editing. Two additional parameters are added specifically for this mode: adapt_thresh (color difference threshold), adapt_align (pre-matching strength - corrects local color spots generated after image merging, the higher the value, the more obvious the correction, but it may have a negative impact on the overall color correction of the scene).
  - Added adapt_local_match parameter, providing more options for mask fusion under the color matching mode Adaptive Local (strong), originally the node only had None mode. Merge feature_amount and adapt_kernel into one parameter feather_kernel.
  - Added support for split image merging in Smart merge images node. That is, when multiple images are input into the edited_crop_B port, the output is a single merged image. Note: The images input into the edited_crop_B port must be a Batch rather than a list. If it is a list, it must be converted by the Image List To Batch node.

## v1.1.3
  
  Added Black White Color node, the mask at the input port will be added with the mask generated by the node by ADD operation.

  The original purpose of ChessboardPattern node was to suppress the pixel offset problem after the style transformation in qwenEdit, first transform the style of the mask area, then transform the invert mask area (however, it needs to be sampled twice, this method does not work in Klein model), and then it was found that the ChessboardPattern mask would affect the model's recognition of objects, so Black White Color node was created. Try to make the area of the black and white regions average to reduce the problem of color inconsistency.

## v0.0.8

  Added Image Noise Using Mask node, which is convenient for adding random noise to the mask area of the image, can adjust the size of the noise, opacity, and can choose whether to be in grayscale mode.
  
  Added Image Pad & Blur node, target width and target height, with input it will automatically calculate the expansion (when the parameter is less than the original image it is clip mode), at this time alignment parameter takes effect, you can choose alignment mode (center alignment, left alignment, right alignment, top alignment, bottom alignment, top left alignment, top right alignment, bottom left alignment, bottom right alignment).

In constant mode, the background_color parameter takes effect, compatible with rgb color and HEX color code (16-bit color code).

## v0.0.6

Empty Image RGB：Supports RGB and 16-bit color information input, the node will automatically identify color information color_code. Output a solid color image, with image size output port, the image size will be approximated based on divisible_by (integer division).

Text Line Break： Breaks the input text into lines based on the number of characters, supports Chinese, English, and mixed Chinese and English, supports punctuation avoidance at the beginning and end. Convenient for connecting prompts and generated images together, which needs to be assisted by other nodes, such as: Add Label node in Kjnode.

Random Chars (Append)：Adds invalid special characters (can customize characters and number) to the input text, mainly to make the generated image have more changes without destroying the intention of the prompt (whether it works or not), because the random change of the image structure generated by qwen_image and Z_image models is small. Here "invalid" is relatively speaking.
                       Can simply set the insertion position (before, end, insert), where insert inserts the number of characters evenly into the position after each punctuation symbol of the original text, from behind forward distribution.
